# OpenValut Rust UI — 任务清单

> 状态图例：✅ 完成 · 🔄 进行中 · ⬜ 未开始

## MVP（已完成）

- ✅ egui/eframe 窗口 + 中文字体加载
- ✅ 打开本地 KDBX（文件选择 / 路径输入 / 记住上次文件）
- ✅ 主密码解锁 / 锁定（密码只在内存，锁定时清除）
- ✅ 分组浏览 + 全库搜索（标题/用户名/网址/备注）
- ✅ 条目详情：用户名/密码/网址/备注，复制到剪贴板
- ✅ TOTP 显示与复制（otpauth:// 与 base32）
- ✅ 新增 / 编辑 / 删除条目，改动后自动保存 KDBX
- ✅ 密码生成器（20 位随机）
- ✅ 全键盘操作与快捷键：
  - 锁定页：`Ctrl+O` 打开文件，`Enter` 解锁
  - 解锁页：`j/k` 或 `↑/↓` 选择，`/` 或 `Ctrl+F` 搜索，
    `Enter` 复制密码，`Del` 删除，`Ctrl+N` 新建，`Ctrl+E` 编辑，
    `Ctrl+S` 保存，`Ctrl+L` 锁定，`Esc` 返回/清除
- ✅ 底栏快捷键提示
- ✅ 精简布局（分组计数、字号/间距统一）
- ✅ 视觉遵循 UI/UX Pro Max 规范（Minimalism & Swiss Style 深色：
  背景 #0F172A、卡片 #192134、强调绿 #059669、去 emoji 图标）
