你的密碼庫，
AI 也能安全呼叫

OpenVault 是圍繞 Rust 記憶體安全核心構建的開源、私有化部署、端到端加密跨平台密碼管理器。主密碼只屬於你，服務端只存密文。讓 AI Agent 在受控通道內呼叫憑證，而無需觸碰明文。

AI 時代，憑證呼叫需要新典範

當 Agent 需要登入網站、呼叫 API 或操作伺服器時，把密碼寫入提示詞或環境變數已不再安全。OpenVault 提供最小權限、可稽核、可撤銷的憑證通道。

最小權限授權

為每個 Agent 單獨授權可存取的條目，精確到單個網站或憑證，避免一次性暴露整個密碼庫。

本地安全通道

憑證僅在已解鎖的本地密碼庫中解密，透過 127.0.0.1 隨機埠 + Unix socket + token 檔案返回，網路不可達。

可稽核 & 可撤銷

每一次 Agent 呼叫都留下紀錄，隨時檢視、暫停或撤銷 Agent 的存取權限，憑證外洩即可一鍵隔離。

不只是密碼管理

從日常登入到開發者工作流，OpenVault 覆蓋完整的憑證生命週期。

端到端加密

Argon2id + AES-256-GCM，主密碼不上傳、不儲存，服務端只儲存密文。

私有化部署

Rust 服務端預設 SQLite，可選 MySQL，可部署在區域網路或公網。記憶體安全、可稽核、完全由你掌控。

自動填充

Android 系統級、Chrome 擴充、iOS Face ID / Touch ID，智慧識別登入表單。

通行密鑰 Passkey

Chrome 擴充支援建立和使用 ES256 通行密鑰，私鑰儲存在本地 KDBX 中。

安全分享

隨機分享金鑰 + X25519 公鑰包裝，只有指定接收方能夠解密條目。

SSH Agent

1Password 風格的 SSH Agent，私鑰僅存於解鎖後的記憶體，支援 ed25519 / RSA。

Rust 記憶體安全核心

加密引擎、KDBX 密碼庫、同步協定與瀏覽器原生訊息宿主均使用 Rust 編寫。所有權與編譯期檢查杜絕關鍵路徑上的記憶體損壞與釋放後使用漏洞。

一處管理，全平台可用

Flutter 構建的客戶端覆蓋桌面與行動裝置，Chrome 擴充與 CLI 打通瀏覽器和終端工作流。

服務端不可信

即使服務端被攻破，攻擊者也只能拿到無法解密的密文。加密參數公開透明，任何人可稽核。

密碼庫加密

  • KDFArgon2id
  • 對稱加密AES-256-GCM
  • 格式KDBX 3.x / 4.x
  • 雲端額外加密Argon2id + AES-256-GCM

傳輸安全

  • 金鑰協商X25519 / P-256 ECDH
  • 請求簽章HMAC + 時間戳
  • 認證郵箱 + UUID Secret Key
  • 權杖Bearer / 30 天
