OpenVault is an open-source, self-hostable, end-to-end encrypted cross-platform password manager built around a memory-safe Rust core. Your master password stays with you; the server only stores ciphertext. Let AI Agents invoke credentials through a controlled channel without ever touching plaintext.

Credential access needs a new paradigm for the AI era

When Agents need to log in to websites, call APIs, or operate servers, writing passwords into prompts or environment variables is no longer safe. OpenVault provides a least-privilege, auditable, and revocable credential channel.

Least-privilege authorization

Authorize each Agent to access only specific entries—down to a single site or credential—so the entire vault is never exposed at once.

Local secure channel

Credentials are decrypted only inside the unlocked local vault and returned through 127.0.0.1 on a random port plus a Unix socket and token file—unreachable from the network.

Auditable & revocable

Every Agent invocation is logged. Review, pause, or revoke an Agent's access at any time, and isolate credentials immediately if leaked.

More than a password manager

From everyday logins to developer workflows, OpenVault covers the full credential lifecycle.

End-to-end encryption

Argon2id + AES-256-GCM. The master password is never uploaded or stored; the server only keeps ciphertext.

Self-hosted

Deploy the Rust server with SQLite (default) or MySQL on your LAN or the public internet. Memory-safe, auditable, and fully under your control.

Autofill

Android system-level, Chrome extension, and iOS Face ID / Touch ID support with intelligent login-form detection.

Passkey

The Chrome extension can create and use ES256 passkeys; private keys are kept in the local KDBX vault.

Secure sharing

Random share keys encrypt entry copies; the share key is then wrapped with the recipient's X25519 public key so only they can decrypt it.

SSH Agent

1Password-style SSH Agent: private keys live only in memory while unlocked, with ed25519 / RSA support.

Memory-safe Rust core

The crypto engine, KDBX vault, sync protocol, and native messaging host are written in Rust. Ownership and compile-time checks eliminate memory corruption and use-after-free bugs in the critical path.

One vault, every platform

The Flutter client covers desktop and mobile, while the Chrome extension and CLI bridge browser and terminal workflows.

The server cannot be trusted

Even if the server is compromised, attackers only get ciphertext they cannot decrypt. Encryption parameters are public and auditable by anyone.

Vault encryption

  • KDFArgon2id
  • Symmetric cipherAES-256-GCM

Transport security

  • Key exchangeX25519 / P-256 ECDH
