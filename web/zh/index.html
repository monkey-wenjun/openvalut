AI 也能安全调用

OpenVault 是围绕 Rust 内存安全核心构建的开源、私有化部署、端到端加密跨平台密码管理器。主密码只属于你，服务端只存密文。让 AI Agent 在受控通道内调用凭据，而无需触碰明文。

AI 时代，凭据调用需要新范式

当 Agent 需要登录网站、调用 API 或操作服务器时，把密码写入提示词或环境变量已不再安全。OpenVault 提供最小权限、可审计、可撤销的凭据通道。

最小权限授权

为每个 Agent 单独授权可访问的条目，精确到单个站点或凭据，避免一次性暴露整个密码库。

本地安全通道

凭据仅在已解锁的本地密码库中解密，通过 127.0.0.1 随机端口 + Unix socket + token 文件返回，网络不可达。

可审计 & 可撤销

每一次 Agent 调用都留下日志，随时查看、暂停或吊销 Agent 的访问权限，凭据泄露即可一键隔离。

不只是密码管理

从日常登录到开发者工作流，OpenVault 覆盖完整的凭据生命周期。

端到端加密

Argon2id + AES-256-GCM，主密码不上传、不存储，服务端只保存密文。

私有化部署

Rust 服务端默认 SQLite，可选 MySQL，可部署在局域网或公网。内存安全、可审计、完全由你掌控。

自动填充

Android 系统级、Chrome 扩展、iOS Face ID / Touch ID，智能识别登录表单。

通行密钥 Passkey

Chrome 扩展支持创建和使用 ES256 通行密钥，私钥保存在本地 KDBX 中。

安全分享

随机分享密钥 + X25519 公钥包装，只有指定接收方能够解密条目。

SSH Agent

1Password 风格的 SSH Agent，私钥仅存于解锁后的内存，支持 ed25519 / RSA。

Rust 内存安全核心

加密引擎、KDBX 密码库、同步协议与浏览器原生消息宿主均使用 Rust 编写。所有权与编译期检查杜绝关键路径上的内存损坏与释放后使用漏洞。

一处管理，全平台可用

Flutter 构建的客户端覆盖桌面与移动，Chrome 扩展与 CLI 打通浏览器和终端工作流。

服务端不可信

即使服务端被攻破，攻击者也只能拿到无法解密的密文。加密参数公开透明，任何人可审计。

密码库加密

  • KDFArgon2id
  • 对称加密AES-256-GCM
  • 格式KDBX 3.x / 4.x
  • 云端额外加密Argon2id + AES-256-GCM

传输安全

  • 密钥协商X25519 / P-256 ECDH
  • 请求签名HMAC + 时间戳
  • 认证邮箱 + UUID Secret Key
  • 令牌Bearer / 30 天
